# 活页 LivePage

让每一页知识，持续生长。

LivePage 是以幻灯片为入口的个人知识与备课工作台：保留原页、积累历次讲解、检索知识、组装课程，并为其他 Agent 提供可追溯的内容。

## 产品入口

- **活页库**：搜索、阅读原图和知识、查看证据与历次讲解。
- **我的课件**：按听众和授课目标选页、排序、保存课程版本。
- **导入资料**：接收 Keynote/PDF 与录音，查看处理结果与待核对项。

## 当前仓库状态

这是从已有个人网站和本地试验工作台拆出的独立产品仓库第一版，包含产品架构、迁移计划、标注规范和最小领域契约。**尚不是已迁移完成、开箱即用的工作台。** 原有网站继续运行；现有私有数据和历史不会随公开仓库发布。

已有系统中的导入、档案、组课与版本能力将按 [迁移路线](docs/ROADMAP.md) 分批迁入。MCP 服务、音频精确回流与 OpenDesign 自动保存回库仍待实现和验收。

## 开发验证

Python 3.10+，当前领域契约检查无第三方依赖：

```sh
PYTHONPATH=src python3 -m unittest discover -s tests
```

## 数据与代码边界

公开仓库只存通用代码、规范和明确标记的合成示例。不包含真实课件、录音、逐字稿、个人标注、生产日志、数据库、媒体素材或凭据。媒体通过存储适配器引用，模型与存储配置由部署环境注入。

仓库公开不等于已确定开源许可；许可证选择待产品所有者确定。
