# 产品定位与用户决策

## 产品使命

产品名：活页 / LivePage。让每一页知识，持续生长。

每页幻灯片是知识节点的入口。用户在不同课程、会议和讲述中反复使用同一内容，将原页、现场讲法、案例、证据、适用情境和修订积累在这一节点下面。未来 Agent 不只检索关键词，还能依据这些上下文理解用户的判断方式。后者是产品目标，不代表已有模型获得了这种能力。

活页包含知识底座、阅读与播放工作台、备课组装能力及 Agent 内容接口。个人网站只是宿主之一；MiMo 和 DeepSeek harness 是处理与执行角色，不是领域模型的不可替换依赖。

## 用户已确认的方向

- 延续已有原子页和设计系统改进，不另造一套互不相通的工作台。
- 首页按原课程体系提供快捷入口；课程内部遵循原始页序。母课程的手工排序可以保存为新版本，原始导入顺序仍保留。
- 左侧展示当前课程页面，右侧展示当前页。目录独立滚动、与画布等高，切换格式不清空目录位置。首次读取目录后可缓存，缩略图按可见范围加载，相邻页预加载。
- 原图和 HTML 在同一画布切换，不默认跳到独立网页；点击全屏才全屏。播放时提供紧凑翻页、页码、目录开关和退出控制，支持键盘。
- 对外投影须简洁、自然。技术编码、总状态、来源细节放在折叠区；不是给观众看的首屏内容。推荐缩略图紧凑，同原子其他出处折叠。
- 标题应表达知识内容，不直接用碎片、序号、缩写或空标题。候选必须保留原始字段、证据与修改记录，不能把 AI 候选当本人确认。
- 用户可以移除不需要的页面；删除与恢复、课程影响范围和历史记录须清楚。
- 备课同时包含 Agent 提案与手工调整：用户说明思路、听众、目标和时长，Agent 生成来源可追溯的组装方案，用户再排序、删改、写讲稿和保存。
- 新导入内容进入统一活页库，不回到旧治理样本工作台。旧工作台可作为导入处理与核验工具，不是默认产品入口。
- 可编辑 HTML 以原稿视觉忠实为第一阶段目标。改设计、套模板和动画升级另作明确任务，不与忠实转换混算。
- 原始课件主要在另一台电脑，转换优先在那里执行。该电脑输出仍须经对照验收，之前生成的草稿有明显走样，不能据生成完成批量宣布合格。

## 人与 Agent 的两种视图

共用身份、来源和版本数据，不维护互相矛盾的两份真源。

给人：可读标题、原图/HTML、课程顺序、真实会议主题、讲述、编辑/备课/播放、必要的待确认提示。

给 Agent：稳定 ID、来源版本及哈希、课程出现位置、原话/AI解读/本人确认分层、证据、讲述时间段、资源健康、结构化框架标签、引用和修改记录。

界面不能堆满 atom 编码、内部模型字段和匹配百分比；接口也不能只给一张图或人类标题而丢失身份与来源。

## 第一阶段范围

以单用户知识与备课闭环为主。暂不把多租户、商业计费、复杂团队协作、全自动发布当作先决条件。代码公开不意味着课件和实录公开；没有许可文件时不宣称已确定开源许可。
