# 可编辑 HTML 本地版本回写（007）

`workbench/html_versions.py` 保存独立、追加式 HTML 表达版本。真实课件与运行记录仅放仓库外私有目录。

- 首版本要求 atom、来源 SHA 和完整单元格身份对应；Docs 返回可增删矩形行列，保留源内容、被删源单元格列表与新增单元格无源状态。
- 每次保存显式指定 base_version_id；跨进程文件锁检查当前版本。完整文件通过同目录临时文件及硬链接原子发布，禁止覆盖已有修订。
- 当前 HTML 和当前单元格文字独立于不变 source_content；原始文字不能因编辑而被重写。
- `patch_cells` 根据现有 cell_id 修改目标内容，执行转义；与 Docs 返回共享基线。重复对象、未知对象、陈旧基线拒绝。
- `get(atom_id, version_id)` 读取固定版本，可用于后续 deck 引用。现有 deck/目录尚未接入此模块，不宣称生产回库完成。
- 仅支持单张、矩形、无跨行列的真实 HTML 表格。当前不提供任意 HTML 安全渲染；返回页的脚本不能直接在主页面执行。
