# 独立化迁移路线

本表是待办，不是完成声明。保留旧入口直到新入口实测通过。

| 阶段 | 交付 | 验收 |
|---|---|---|
| 0 仓库与契约 | 通用规范、产品边界、合成样例 | 无真实资料/凭据入库，领域检查通过 |
| 1 只读统一 | 抽取档案与库 API、旧数据适配器、统一 UI | 原子/出现位置计数对账；旧 ID 可解析；高清图可读 |
| 2 写入统一 | 笔记、组课、页面版本、事件 | 并发冲突不覆盖，历史可恢复，重复使用事件不多计 |
| 3 最小产品闭环 | 搜索→组课→OpenDesign编辑→回库→再次读取 | 真实编辑内容和版本均可追溯，旧课程不静默改变 |
| 4 音频知识闭环 | 一场录音、时间戳、人工核对关联 | 原子详情可定位原声；多人归属和对齐候选清楚 |
| 5 MCP | 读工具先行，再增加有权限的写工具 | 外部Agent检索/引用真实节点并返回来源；权限测试 |
| 6 批处理 | 模型适配、重试、质量检查、增量导入 | 代表页质量验收后扩大；失败保留输入与已完成结果 |
| 7 独立生产部署 | DB迁移、对象存储、认证、备份 | 迁移前后数据一致、回滚演练、宿主入口切换 |

旧应用代码不能直接整目录复制：先移除私人路径和数据依赖，提供合成演示，再逐模块迁入。本仓库不附带个人站自动部署工作流。
