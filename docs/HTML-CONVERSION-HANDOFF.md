# 给原始文件所在电脑：LivePage HTML 转换管线整改交接

日期：2026-10-11

## 用户要求与任务边界

原始课件在另一台电脑，由那台电脑执行 HTML 处理。目标是原稿忠实、元素可编辑、可在 LivePage 内嵌并用于投影播放。不是重新设计课件，也不是把整页 JPG 放入 HTML。文字、表格和基础图形应可编辑；照片及复杂暂未重建图形允许保留图片，必须记录不可编辑区域。

本文件是执行交接，不代表另一台电脑已经收到、执行或上线。当前本机只检查到公开结果与本地工作台；尚未验证另一台电脑实际运行的全部管线代码、模型提示词及原始文件。

## 当前可复现问题

样例：atom-0001，原始出现位置 mba-229（产品形态 PF / 功能集合 FS / 成本结构 CS）。

- 原稿基准：私有工作区 assets/legacy-hd/mba-229.jpg。
- 当前公开结果：https://qiuyiwu.com/slides-html/atom-0001.html 。
- 工作台对照：http://127.0.0.1:5198/atom-pages/atom-0001.html ，在同一画布切换原图与 HTML。
- 当前 HTML 文件头注明由 pipeline/slide_render.py 从 JSON 渲染，JSON 是真源。请先核实实际执行版本与 JSON 来源，不能只手改输出 HTML。

已检查的源码与截图证据：

1. 外层已使用 16:9、container-type 与 cqw 坐标，但正文缺少与原稿匹配的独立布局和字体控制。只有外框坐标准确不能保证整页准确。
2. 卡片 CSS 将背景写成纯白、边框写成黑色实线；原稿的浅色透明底、圆角、点线边框、分隔线未正确重建。
3. 卡片标题没有正确居中，PF/FS/CS 的紫色强调、段落加粗和段间距没有完整保留。
4. 正文密集在左上；另一次截图显示正文变大、重新换行、底部裁切。确定存在字体/布局失控；浏览器缩放、字体回退或具体样式继承是否参与，尚待执行电脑复现，不能只归因于 iframe。
5. 原稿浙江大学 Logo 未正确显示。需要区分素材未提取、槽位变量未生成、资源路径或加载失败。
6. 其他页面曾出现文字乱码；必须在内容校验中拦截，不能仅依据生成成功判断完成。

本机工作台另有左栏高度跟随隐藏原图变为零的问题，已修改为跟随当前可见画布；这是播放器问题，与转换版式问题分开验收，修好左栏不代表 HTML 已合格。

## 需要修改的管线

### 1. 建立每页来源与视觉基准

优先用原始 .key，经 Keynote 导出 PDF 和高清页面图，保留原文件哈希、导出参数、画布尺寸、课程 ID、源页号、跳过页状态、导出时间。用导出 PDF 的文字及几何信息辅助提取，图像识别补充不能读取的对象。

原子 ID 与课程出现位置必须分别保存；一个原子多次出现不能把某个版本的转换盲目套到所有版本。源版本改变后，旧验收状态失效。

### 2. 修复中间结构 JSON

逐块保存 bbox、元素类型、文字原文、显式行划分、字体及字重、字号、行高、字距、对齐、颜色、段内强调、背景、透明度、圆角、边框、分隔线、图片裁切和层级。标题与正文独立建模。

缺失字段记录 missing/uncertain，不静默补成浏览器默认样式。保留模型、提示词版本、解析器和渲染器版本，以及修改记录。不要用原稿不支持的新内容填补识别缺失。

### 3. 修复确定性渲染器

使用固定源画布，所有元素使用一致坐标体系；展示窗口变化时整体等比例缩放。正文不能在窄窗口自行重新排版。按原稿保存换行，提供明确字体和行高。字体文件应可访问并检查实际加载，缺字体或素材时显式报错。

资源使用可携带的相对路径或明确资源清单。确认在 LivePage 的无脚本 sandbox iframe 中也能正确显示；单独浏览器正常不等于内嵌正常。若确实需要脚本播放动画，作为独立能力说明，先与播放器约定权限。

### 4. 增加渲染验收与修正循环

在固定浏览器、固定视口和缩放条件下，等待字体、图片加载后截图。以原稿尺寸对照输出：原图、渲染图、并排图、半透明叠加图、差异报告。

自动检查内容遗漏/乱码、元素越界、重叠、文字裁切、资源失败与字体回退。视觉差异指标用于定位问题，不单凭一个相似度分数批准。对文字块、图形、照片分别分析，避免字体抗锯齿造成误判。

失败应回到 JSON 或渲染器修正并重新生成。人工确认关键页面，保留确认人、时间、版本与残留差异。

## 执行顺序与交付物

1. 先复现 atom-0001，找到结构提取与渲染丢失样式的具体位置。
2. 修 JSON schema / 提取器 / 渲染器，重新生成此页，在原始尺寸及 LivePage 内嵌尺寸检查。不要只交一张截图或手工修版。
3. 验证至少纯文字、三栏框架、图片混排、表格、复杂图表五类代表页面，并测试字体密集/长句页面。
4. 样例通过后，小批次运行；按失败类型汇总再扩到全库。失败页保留原图播放。
5. 每批交付：源清单、结构 JSON、HTML 与素材、对照图、问题报告、验收状态、失败列表和可复现命令。更新转换清单供 LivePage 读取。

状态须区分：generated（已生成）、render_checked（已渲染检查）、visual_review_pending（待视觉确认）、accepted（已确认）、failed（失败）。已有 pixel-compare 标签不得直接迁移成 accepted，须找到对应实际证据。

## 播放器接入要求

HTML 在每个活页右侧同一个画布内嵌，与原图切换；课程目录保持原始顺序、滚动位置和高度，切换格式不重新加载目录。点击全屏后才全屏，提供翻页与目录开关。

投影默认使用已验收 HTML，其余回退到原图。生成、验收、部署分别记录，不能将生成数量当作正式可播放数量。
