# 上下文备课台（008）

2026-10-15，独立页面 workbench/preparation.html，原assembly页面保留并增加入口。

## 产品流程
授课主题/听众/意图 → 按问题检索深脑、著作、活页 → 有来源的理解/推断 → 讲者纠正并确认 → 推敲结构 → 逐段编辑与讲稿 → 另存组课与播放。

人工修正是备课版本记录，不回写深脑或著作。重新读取理解、修改授课意图或修改结构会使下游草稿失效；历史快照保留，网页可只读查看。

## 来源与边界
- 深脑使用用户提供的官方GET API只读适配，尚未包装为新的MCP协议服务。
- 检索器先规划4—6条短查询，对转写标题排序并读取片段；额外读取动机/转折片段。可接受已有阅读记录ID提示。不是全库语义检索或“已理解全部人生”。
- 只把明确邱懿武/qiuyiwu说话人前缀的转写交给模型作作者材料；其他/未知身份片段可查看，不进作者推理上下文。原音仍未听校。
- 著作目录与正文分开：目录保留published/online/在写等状态，正文每部最多2段，总计10段。当前未自动验定作者身份或出版状态。
- 活页只读取可见提取文字和身份，不拿旧AI摘要冒充现场讲法。
- source_id、内容哈希、版本时间、原文字符偏移/时间锚点与正文一起保存，供审阅核对。

## 配置
服务器仅从受限环境读取 SHENNAO_API_KEY、PREP_BOOKS_INDEX、PREP_BOOKS_CATALOG；可用PREP_CONTEXT_ENV_FILE显式指向受限env文件。不得在网页、代码仓库或公开日志中保存密钥。
模型复用prep_agent配置及provider，不接Token Plan到网页后端。
生产run_production禁止静态访问data/preparations与data/prep-context-cache；业务API继续受宿主登录保护。

## 生成与持久化
- 2个后台线程上限；生成返回202，前端读取状态。模型或来源异常不会改母课。
- JSON引用白名单、引文字段逐字检查、说话人归属闸门。最多1次修复，不靠不断重试覆盖错误。
- 模型提案是pending；Agent验收推进明确标记agent_test，不能当作本人确认。
- 讲述时间为草案；模型合计不符时按比例收拢到目标并显示原始分钟数。不是排练实测时间。
- 讲稿有独立输出预算、可逐段编辑与下载。编辑说明与口述稿分开。
- 所有备课追加版本，基线冲突409；重启使中断任务明确失败，不永久停在running。
- 另存课件复用assembly领域接口；批量读取新页一次，已存引用更新不重复读全库。

## 后续质量工作
1. 在用户真实审阅中检验理解/讲述是否像他；模型通过结构校验不等于内容满意。
2. 增强章节上下文、查询覆盖与跨场演变；避免片段命中替代完整阅读。
3. 完善每段讲法比较、选材替换、原创页面与录音回流。
4. 正式MCP工具适配可复用现有只读connector，不把API包装当知识理解完成。

## 组课映射审计补充
