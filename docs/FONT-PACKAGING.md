# 静态幻灯片字体打包

工具 workbench/optimize_slide_fonts.py：保留原输入，输出独立候选和字体QA。仅支持无脚本、无CSS生成文字的静态页；动态文本拒绝处理。对内嵌WOFF2按本页文字裁字，保留布局特性，校验字符覆盖与advance metrics；非字体字节不变。不重置既有来源或验收状态。

运行需 fonttools、brotli（workbench/requirements.txt已声明）。例如：
python workbench/optimize_slide_fonts.py source.html --out candidate.html

私有第三页实测：1,877,450 → 270,790字节，约减少85.6%。六份字体逐份检查通过；非字体内容一致。本地1280×720浏览器前后目视对照未见排版变化。这不是全库验收，也不是对原稿转换质量的重新认可。

当前工具已落地，尚未挂到另一台电脑的转换执行器或公开回库接口。编辑增加新字符后必须从完整字体重新打包，不直接复用旧子集。线上读取和离线导出均可先保持自包含格式，避免破坏现有回库的内嵌资源约束。跨页共享字体优化需另设在线资源适配，不能直接改变离线制品契约。
