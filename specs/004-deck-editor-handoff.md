# 004：Deck 与外部 HTML 编辑交接

## 要什么
活页可编排为deck；每个位置引用明确页面版本。同一活页可重复出现，编辑生成新版本，旧deck不静默改变。HTML文字保留独立对象ID，为OpenDesign Docs导入和回写准备证据。

## 不做什么
不把opendesign.cc资源库当编辑器；不猜测第三方API；不宣称contenteditable等于完整编辑器。不部署、不批量改历史数据，不用截图代替文字。

## 验收清单
- [x] 确认入口doc.opendesign.cc，静态核实HTML与postMessage导入；导出与真实往返待验。
- [x] 活页侧实验交接包绑定来源哈希、页面版本、HTML哈希、稳定文字对象ID。
- [x] deck位置有独立entry_id，可重复引用同一页面；顺序及版本明确。
- [x] 交接包拒绝文字截图；模型输出默认pending。
- [ ] 一页导入真实编辑器，改文字/布局，保存导出，核对字体、图片、对象ID。
- [ ] 返回新版本，验证编辑基线；冲突不能覆盖已有版本。
- [ ] 永乐deck参考落实为目录/进度/键盘/触屏/URL定位，编辑状态不触发翻页。

## 实现约束
交接格式先作为LivePage自有实验契约，第三方适配独立实现。SVG图形暂整层保留，不能声称图形/表格已经对象化。HTML与来源制品必须可追溯；返回HTML需要安全隔离及资源校验。

in-progress；用户已授权继续，第三方接口待确认。
